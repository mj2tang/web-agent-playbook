### Team

**You own the epic's exit condition.** Several independent features go to the agent team.

1. Freeze `tasks/EPIC.md`: goal, non-goals, and an exit condition a command can check.
2. Hand it to the orchestrator (skill `orchestrate-team`): wave 0 contract and design, then trust-sized waves of workers, supervisor review, merge train.
3. Keep a decision trail (skill `decision-log`) when you step away; use `pause-and-resume` before stopping.

**Reply:** exit-condition status, the task table with evidence, the trust level, and the decisions waiting on a human.
